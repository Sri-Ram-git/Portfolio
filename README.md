## Before Deploying — Replace These Placeholders

Open `index.html` and find + replace:

| Placeholder | Replace with |
|---|---|
| `your@email.com` | Your real email |
| `YOUR_LINKEDIN` | https://linkedin.com/in/yourprofile |
| `YOUR_GITHUB` | https://github.com/yourusername |
| `YOUR_RESUME_PDF` | Link to your resume PDF |
| `YOUR_GITHUB_LINK_HERE` (×3) | Each project's GitHub repo URL |
| `YOUR_DEMO_LINK_HERE` (×3) | Each project's demo URL (or remove the Demo button) |

## Deploy for Free — 3 Options

### Option 1: GitHub Pages (Recommended — Free)
1. Create account at github.com
2. New repository → name it `yourusername.github.io`
3. Upload all files (index.html + assets folder)
4. Go to Settings → Pages → Source: main branch
5. Your site is live at `https://yourusername.github.io`

### Option 2: Netlify (Drag & Drop — Easiest)
1. Go to netlify.com → Sign up free
2. Drag your entire `sriram-portfolio` folder onto the deploy zone
3. Live in 30 seconds at a random URL
4. Rename to `sriram.netlify.app` in settings

### Option 3: Vercel
1. Go to vercel.com → Sign up with GitHub
2. Import your GitHub repo
3. Deploy → live at `yourproject.vercel.app`
